# Phase 1: 迁移前性能与契约基线报告

## 一、 性能基线实测数据 (Python 3.15.2 双 Worker)

测试基准环境：公网客户端发起，经过 OpenResty 反向代理到达 `cycle-compass-api` 容器，服务器规格为 2 vCPU / 1.9GiB 内存 / Debian 13。

| 指标项 | 实测数值 | 测量方式与说明 |
| :--- | :---: | :--- |
| **容器常驻物理内存 (RSS)** | **223.9 MiB** | `docker stats` 实测（Uvicorn 双 Worker + Pandas/NumPy） |
| **容器内存硬配额** | 512.0 MiB | 当前内存占用率约 43.7% |
| **单请求 P50 延迟** | **38.62 ms** | 50 次串行采样中位数（包含网络往返） |
| **单请求 P95 延迟** | **43.06 ms** | 95 分位延迟 |
| **单请求 P99 延迟** | **257.03 ms** | 偶发网络抖动与 GC 暂停导致的峰值 |
| **100 并发吞吐量 (QPS)** | **153.6 req/s** | 100 协程并发打向核心行情接口实测 |
| **错误率** | **0.0%** | 100 请求全部返回 HTTP 200 |
| **冷启动初始化耗时** | ~3.5 秒 | Uvicorn 加载全量依赖与路由的耗时 |

## 二、 API 契约黄金基线快照

所有接口均已固化真实生产响应快照至 `tests/golden_api_snapshots/` 目录：
1. `root.json`: 根路径元数据
2. `health.json`: 健康监控结构
3. `quotes_batch.json`: 核心观察池多资产行情数组
4. `quote_single.json`: 单标的详细报价与元数据
5. `sectors_metrics.json`: 24 条产业链评分与周期阶段
6. `cycles_overview.json`: 宏观周期罗盘状态与股债利差
7. `rotation_signal.json`: 创业板50/红利低波比值轮动信号
8. `scoring_detail.json`: 红利低波四维评分与定投金额
9. `combined_signal.json`: 双策略联合决策
10. `portfolios_overview.json`: 模拟持仓、盈亏与审计流水
11. `backtest_run.json`: 300 天真实历史回测绩效输出

## 三、 迁移目标验收阈值

Go API 迁移完成后必须达成以下硬性门槛：
1. **内存占用**：Go API 容器常驻内存必须 **< 40 MiB**（相比 Python 降幅 $\ge 80\%$）。
2. **延迟指标**：P50 延迟 **$\le$ 20 ms**，P99 延迟 **$\le$ 100 ms**。
3. **接口契约一致性**：上述 11 个接口在字段名、数据类型、状态码、空值行为上实现 **100% 兼容**。
4. **服务启动耗时**：从容器启动到监听端口就绪 **$\le 100$ ms**。
