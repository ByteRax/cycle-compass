# 周期罗盘 V4 · UI 设计交付规范

以仓库用户批准的方向一（精密航海仪器盘）×方向四（三环信号颜色编码）为基座：墨曜石暗场、铜金刻度、细线边界、等宽数字。新增金融资产专属浅色阅读主题。设计以375×812逻辑像素（750rpx）为基准，PNG 为3倍分辨率。所有样例数据固定为演示，不是市场事实，界面不是实机截图。原型 HTML 使用标准 Web HTML/CSS/SVG 以便可精确截图，实际微信小程序要按实施提示改用 UniApp 组件、Canvas 2D 和平台安全区；SVG 不可原样内嵌 WXML。

## 组件与交互

- 顶栏以平台 API 测量微信胶囊/安全区；页头只展示一级标题与状态，小型图标保持44×44实际触控区。375px时页面边距12–14px；列表内6–8px列间距，数字右对齐，主标题20–24px、行情14–16px、辅助说明11–12px，密集表至少12px；图例最低10–11px，窄屏隐藏非必要列，不缩小全部文本。
- 行情页底部保留四项 `策略/行情/产业/账本`，金融分包不使用第二个全局TabBar；子页面顶部返回、资产/图表选择器与安全区工具条。筛选/搜索/滚动复原。旧 divergence 深链数字1–6保持兼容，第7项为 tier。
- 资产表列宽按可用宽度动态分配，品种列优先，价格/成交额/强度用 tabular-nums；标签最多2行，更多展开。右侧使用浅铜金强调，不拿趋势颜色当涨跌。温度色独立于涨跌色；0、未知和不适用分开，不能只靠颜色。
- 七图工作台每页共用头部、范围和工具栏。图表类型用两行切换（设计稿），长表用独立页面滚动；真实实现可横向可滚动、swiper切换但避免与 Canvas 手势冲突。图例筛选、十字线、缩放、标签避让和长名称 tooltip 需验证；x/y轴及百分比语义正确。图表自身无成员能力时隐藏/禁用并解释。
- 列表、图表、报告使用同一不可变快照及实际数据日期；界面设计示例使用统一固定演示快照。报告可用浅色/暗色，1080px宽，自适应长图，超过设备限制分页；数据出处、版本、范围、统计方法、品牌与二维码区域清晰。分享图与阅读版分离，禁止普通截图拼凑。
- `tokens.json` 是对现有品牌颜色的扩展建议；`#E5B352` 金色不等于收益上涨，冷暖色用于温度/状态需同时保留文本。深色辅助文字对比度≥4.5:1优先，浅色金需变深。原型截图是视觉示例，生产根据系统字体、大字体、微信真实胶囊/底部安全区调整。
- 所有页面需具备 loading、refreshing、stale、market_closed、not_covered、insufficient、empty_filter、error；收藏/分享配置/导出需反馈成功失败，不能用模拟 data fallback 表示线上成功。

## 文件用途

`index.html` 可在浏览器离线打开，左侧目录切换22个视图；趋势图切换、主题、页面跳转及部分选择提供演示交互，其他标记和数据为固定布局参考，不代表真实功能。`screens/*.png` 为单屏参考，`reports/*.png` 为七种分享报告（示意合成数据）；总览按模块排列，不作为像素精确验收依据。实现时以单屏和本规范为准，并按 `IMPLEMENTATION_PROMPT.md` 补齐真实业务交互。


补充：`design/scroll-states/`（设计规范内相对目录为 `scroll-states/`）包含9张补充截图，用于查看折叠、长列表滚动后及图表下半部分；五张 overview 总览图按核心模块组织。`render-check.json` 记录浏览器原型渲染检查（无 JS 错误、22屏无横向溢出及基本导航/主题/搜索通过）。不是微信真机测试，也未运行项目代码。
