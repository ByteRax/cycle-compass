# 周期罗盘 · 金融资产 V4 实施交付包

目标：在已上线 CycleCompass 的基础上，将当前六图原型升级为真实数据驱动、可复核、可持续运营的金融资产研究模块；不推倒既有策略、行情、产业和账本业务。

## 使用方法

1. 解压到本地。将本包放在项目外或项目内 `docs/finance-v4-design/`（不要把参考图和演示数据打包进小程序主包）。
2. 将 `IMPLEMENTATION_PROMPT.md` 全文交给 ZCode、Codex 或 Claude Code 的 Goal 工作模式；指明当前项目及本包目录。先阅读 `docs/REPO_AUDIT.md`，按阶段执行，不要盲目重复造轮子。
3. 打开 `design/index.html` 离线查看原型；点击页面目录切换设计稿，图表类型、主题、范围等部分控件支持预览交互。`design/screens/` 是 375×812 CSS 逻辑尺寸、3倍图的单屏 PNG；`design/reports/` 是七类独立分享报告 PNG；总览图用于快速浏览，单屏用于对照实现。
4. `design/DESIGN_SPEC.md` 是尺寸、组件、图表和状态交互的规范，`design/tokens.json` 为建议样式 token；`docs/ACCEPTANCE.md` 是验收清单。设计示例使用固定演示快照及合成数据，不是实时市场行情，不代表竞品算法或生产数据。原型 HTML 是视觉参考，不可直接复制为 WXML。

## 重要决定与边界

- 保留底部四 Tab（策略 / 行情 / 产业 / 账本），金融资产作为行情页的新入口与分包；保留原 divergence 路由及参数兼容。避免另造全局 TabBar。
- 沿用项目已经批准的 #090C0F / #12161B / #E5B352 设计基座，浅色作为金融模块新增主题能力，优先保证暗色；七档温度保留，分档阈值仅为自研 v1 候选方案。
- Go + chi + SQLite，既有 Python 研究服务保留；不擅自迁移数据库或改动生产部署，不接入真实交易。不以演示样例或当天日期伪造真实数据。
- 截图已验证六类核心图表与独立强度分层榜；将分层榜纳入七图工作台是本次自主设计。原竞品的综合指数、温度、节气及数据源仍未完全公开，不承诺数值复刻。
- 数据商授权、公开展示资质、真实行情接入、微信真机效果需实施阶段验证；本包不是已经实现或通过测试的业务代码。若合法授权不足，以未覆盖状态呈现，不用假数据填补。


补充：`design/scroll-states/`（设计规范内相对目录为 `scroll-states/`）包含9张补充截图，用于查看折叠、长列表滚动后及图表下半部分；五张 overview 总览图按核心模块组织。`render-check.json` 记录浏览器原型渲染检查（无 JS 错误、22屏无横向溢出及基本导航/主题/搜索通过）。不是微信真机测试，也未运行项目代码。
