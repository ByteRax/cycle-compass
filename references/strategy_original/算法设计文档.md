> 依据：xcnbeta「指数轮动笔记」图集（35 篇 / 131 图）识别归纳，详见《笔记内容识别整理》。
> 交付：本设计文档 + 可运行 Python 实现（`index_rotation/` 目录）+ 校准验证脚本。
> 定位：**忠实复现笔记作者的策略规则**，供学习研究；不构成投资建议。

## 〇、两套系统如何配合

作者用两个独立系统分别回答投资的两个问题：

```
                  每日/每周收盘数据
                        │
        ┌───────────────┴───────────────┐
        ▼                               ▼
  【轮动系统】                      【打分系统】
  创业板50 ÷ 红利低波100            红利低波100 四维打分
  → 决定【买不买、买谁】             → 决定【买多少】
  三区间开关                        0~20 分 → 八档金额
        │                               │
        └───────────────┬───────────────┘
                        ▼
              若轮动系统判定"空仓不买"，
              则打分结果仅作参考、不执行买入
```

> 笔记《解释2》原文分工：**"轮动打分告诉你今天买还是不买；红利100打分告诉你买多少。要是轮动系统告诉你今天不买，就直接不要看红利低波打分了。"**

## 一、轮动系统（Rotation System）

### 1.1 输入数据

| 输入 | 字段 | 说明 | 来源口径 |
|------|------|------|----------|
| 创业板50 收盘价 | `growth_close` | 指数 399673，日频 | 腾讯日线 |
| 红利低波100 收盘价 | `dividend_close` | 指数 930955，日频 | 中证官网；T+1 更新，当日未发布时用 515100/159307/159549 三只 ETF 日涨跌幅**中位数推算**（实测误差 0.10%/0.03%/0.14%） |
| 历史比值序列 | `hist_ratios` | 用于算近 1500 日分位（仅参考） | 由两收盘价历史序列计算 |

> 旧版（9/28~9/30）输入为创业板指 399006 ÷ 中证红利 000922，阈值 0.34/0.55；10/05 起升级为上述新版。

### 1.2 核心规则

**比值**：`ratio = 创业板50收盘 ÷ 红利低波100收盘`

**三区间开关**（真正触发买卖的是绝对比值线，分位仅参考）：

| 区间 | 条件 | 动作 | 标的 | 10年时间占比 |
|------|------|------|------|--------------|
| 低区 | ratio < 0.16 | 定投 + 越跌越买 | 创业板50 ETF **159949** | ~24.5%（约119周）|
| 中间区 | 0.16 ≤ ratio < 0.28 | **空仓**，定投额进现金池 | 现金池（可放国债ETF 511260）| ~53.9%（约262~268周）|
| 高区 | ratio ≥ 0.28 | 定投 + 长持吃股息 | 红利低波100 ETF **515100** | ~21.6%（约105周）|

**辅助规则**：
1. **一次性回补**：离开中间区的**次周定投日**，把现金池累计金额一次性买入新区间对应标的，再恢复每周 1000 元定投。留一周缓冲防情绪化；中间区占多数时间，不回补会错过第一段行情。
2. **股息复投**：红利低波100 按 5.0%/年、创业板50 按 0.6%/年逐日计提，分红即再买入。
3. **现金池**：默认零息（保守口径）；若买十年国债ETF(511260)年化约 3.76%（整体约 +0.14pp）。

### 1.3 计算流程

```
每个交易日：
  ① 算比值 ratio = growth_close / dividend_close
  ② 判区间 zone = 低区/中间区/高区
  ③ 若当日为"每周首个交易日"（定投日）：
       a. 若 zone≠中间区 且 现金池>0 → 先用现金池一次性回补该区标的（扣买入费）
       b. 再执行本周定投 1000 元：
            低区 → 买创业板50；高区 → 买红利低波100；中间区 → 进现金池
  ④ 股息逐日计提复投：持仓份额 ×= (1 + 年股息率/365)
  ⑤ 现金池逐日计息（默认零息）
  ⑥ 记录当日总资产 = 创业板市值 + 红利市值 + 现金池
回测结束：计算 XIRR、最大回撤、期末资产、区间分布等
```

### 1.4 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `low_line` | **0.16** | 低区线（6段独立寻优中位 0.14~0.17）|
| `high_line` | **0.28** | 高区线（6段中位 0.24~0.30；须保红利定投时间≥20%）|
| `weekly_amount` | 1000 元 | 每周定投额 |
| `fee` | 0.05% | 买入费率 |
| `div_yield_dividend` | 5.0%/年 | 红利低波100 股息率（假设值，±1pp→年化±0.2pp）|
| `div_yield_growth` | 0.6%/年 | 创业板50 股息率 |
| `cash_rate` | 0（保守）| 现金池年化利率 |
| `quantile_window` | 1500 日 | 分位参考窗口 |

### 1.5 输出结果

- **单点信号卡**：当前比值、所处区间、本周动作、近1500日分位、回高区需涨%、距低区需跌%
- **回测绩效**：期末总资产、总投入、净盈利、含息年化 XIRR、最大回撤、三区间天数分布、累计股息、一次性回补次数、逐日净值序列、逐周定投流水

> 笔记口径参考：10年区间 0.1204~0.4399，均值约 0.2183、中位约 0.1953；信号卡显示的"回高区需涨"=`(0.28/ratio-1)*100`，"距低区需跌"=`(1-0.16/ratio)*100`。

## 二、打分系统（Scoring System）

### 2.1 输入数据（每日收盘后）

| 输入 | 字段 | 说明 |
|------|------|------|
| PE 历史分位 | `pe_percentile` | 红利低波100 当前 PE 在**历史全部交易日**中的分位，0~1（只用过去数据防未来函数）|
| 股息率 | `dividend_yield` | 红利低波100 股息率，% |
| 十年国债收益率 | `bond10y` | % |
| RSI(70日) | `rsi70` | 0~100 |
| 布林 %B(100日) | `b_pct100` | 常见 0~1，>1 表示突破上轨 |
| 红利÷创业板强弱分位 | `style_percentile` | 该相对强弱的历史分位，0~1 |

### 2.2 核心规则（四维打分 → 总分 → 八档金额）

**四维各算 0~100 便宜度**（分越高越便宜），映射公式经笔记样例校准：

| 维度 | 权重 | 公式 | 含义 |
|------|------|------|------|
| 技术面 | **50%** | `0.45×(100−RSI) + 0.55×100×(1−%B)` | 越超卖、离上轨越远分越高 |
| 股息利差 | **25%** | `利差pp ÷ 4 × 100`（4pp 封顶）| 利差=股息率−十年国债，越大越划算 |
| 估值面 | **15%** | `(1 − PE分位) × 100` | PE 分位越高越贵、便宜分越低 |
| 市场风格 | **10%** | `(1 − 风格分位) × 100` | 红利相对创业板越被冷落分越高（逆向）|

**总分**：`total = (技术×0.50 + 利差×0.25 + 估值×0.15 + 风格×0.10) ÷ 5` → **0~20 分**

**评分 → 八档金额**（基数 200 元/交易日）：

| 评分 | 倍数 | 金额 | 评分 | 倍数 | 金额 |
|------|------|------|------|------|------|
| ≥18 | 5倍 | 1000元 | 10~12 | 1倍 | 200元 |
| 16~18 | 4倍 | 800元 | 8~10 | 0.5倍 | 100元 |
| 14~16 | 3倍 | 600元 | <8 | 空仓 | 0元 |
| 12~14 | 2倍 | 400元+买回 | ≤6/4/2 | 减仓 | 卖25/33/50% |

**三池规则**：股息池自动复投、卖出池评分≥12 买回、现金池（少投的钱）按 1.7% 计息。**空仓≠清仓**：只是暂停买入，持仓不动、股息照收。

### 2.3 计算流程

```
每日收盘后：
  ① 取四项原始指标 + 两个分位
  ② 分别算四维便宜分：技术/利差/估值/风格（各0~100，钳制边界）
  ③ 加权平均 ÷ 5 → 0~20 总分
  ④ 总分 → 八档映射 → 当日投入金额 / 是否减仓
  ⑤ 资金池更新：正常买入扣基数、少投的钱进现金池、股息复投、卖出池待评分≥12买回
```

### 2.4 关键参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 四维权重 | 50/25/15/10% | 现行日频版；早期周频版为 55/15/10/20（技术/利差/估值/风格）|
| `base` | 200 元/交易日 | 定投基数（一周1000、一月约4000）|
| `BUYBACK_LINE` | 12 分 | 卖出池买回线 |
| `REDUCE_LINES` | 6 / 4 / 2 分 | 减仓触发线 |
| `REDUCE_RATIOS` | 25% / 33% / 50% | 对应减仓比例 |
| `CASH_RATE` | 1.7% | 现金池年化利率 |

### 2.5 输出结果

- 四维各自得分、股息利差(pp)、**总分(0~20)**、当日动作、投入倍数、投入金额、减仓比例
- 历史参考：评分峰值 15.5(2021-07-30)、低谷 1.3(2018-01-24)；档位分布（减仓117/空仓361/少买641/正常687/多买286/加码71 天）

## 三、校准与验证结果（重要）

打分系统的四维映射公式笔记未逐字给出，本实现**用笔记披露的真实样例点反推并校准**：

**A. 完整链路（原始指标 → 四维分 → 总分）**

| 样例 | 计算总分 | 笔记总分 | 误差 |
|------|---------|---------|------|
| G13 10-13 | 9.22 | 9.20 | +0.02 |
| G28 11-03 | 7.02 | 7.00 | +0.02 |
| G35 11-20 | 6.73 | 6.72 | +0.01 |

**B. 四维加权（11 组样例）**：平均绝对误差 **0.012 分**，最大误差 **0.047 分**

**C. 轮动系统**：6 个真实样例点区间判定全部正确；"回高区需涨+51.5% / 距低区需跌13.4%" 与笔记**完全一致**。

> 结论：实现与笔记作者的算法高度吻合，可视为对原策略的可靠复现。

## 四、代码结构与使用

```
index_rotation/
├── scoring.py         # 打分系统：四维打分 + 总分 + 八档金额
├── rotation.py        # 轮动系统：比值/区间/信号卡 + 周频回测引擎(含XIRR/回撤)
├── demo_scoring.py    # 打分校准验证（真实样例点）
└── demo_rotation.py   # 轮动验证 + 合成数据回测演示
```

```bash
cd index_rotation
python3 demo_scoring.py   # 查看打分系统校准结果
python3 demo_rotation.py  # 查看轮动系统验证与回测演示
```

**对接真实数据**：把 `growth_close`/`dividend_close`（日频收盘价序列）和打分所需六项指标替换为真实行情即可。打分系统的 PE分位、风格分位须用"截至当日的历史序列"计算（`percentile_of`），避免未来函数。

## 五、局限与诚实声明

1. **打分公式为反推**：四维映射的具体系数（0.45/0.55 等）由样例点反推，虽高度吻合，但不保证是作者原始代码的精确形式；总分公式（加权÷5）与权重为笔记明确给出。
2. **回测口径**：笔记回测为**样本内事后回测**，作者本人也披露"真实增益有限、参数为样本内最优、合理预期应下调至 7%~10%"。股息率 5% 为假设，最大回撤达 -33%。
3. **合成数据演示**：轮动回测演示使用合成比值路径，仅验证机制正确性，收益数值无实际参考意义。
4. **本实现仅供学习研究**，不构成投资建议，实盘盈亏自负。

## 六、Review 后的工程化修订（2026-11-21）

### 6.1 原实现的主要问题

| 问题 | 影响 | 修订 |
|---|---|---|
| 只有公式和演示，没有真实取数入口 | 无法每天自动运行 | 新增 `data_provider.py`，接入中证指数官网、腾讯/新浪行情、东方财富国债收益率，并写入本地缓存 |
| 打分缺少明确的指标计算口径 | RSI/%B/分位无法复现 | 新增 `indicators.py`：Wilder RSI(70)、布林%B(100, 2倍标准差, ddof=0)、严格的截至当日历史分位 |
| 风格分位定义模糊 | 无法自动化 | 验证为红利低波100÷创业板50近1500日分位；11/20 全历史接口算出75.7%，与笔记75%吻合 |
| 现金池可能同周提前回补 | 破坏“次周回补”规则 | 回测和执行状态均记录跨区所在周，只有下一个定投周才回补 |
| 低分状态每天重复输出减仓 | 重复执行会过度卖出 | `execution.py` 只在首次进入更深减仓档时产生事件；8分以上才解除档位，12分以上才买回卖出池 |
| 账户价值回撤受持续入金扭曲 | 回撤数字失真 | 回测另建单位化净值序列计算最大回撤；股息/现金利息按自然日间隔计提 |
| 重跑会重复记账 | 定时任务重试不安全 | 按日期幂等，历史 CSV 同日覆盖，状态原子写入，进程独占锁防并发 |
| 没有数据新鲜度检查 | 节假日或接口故障可能用陈旧数据 | 行情与辅助数据分别检查滞后期，超限直接停止打分并报错 |
| 原始打分与轮动开关混在一起 | 用户分不清“信号”和“执行” | 同时输出原始打分、轮动门控后金额、当日实际状态事件 |

> 三个指定能力中，综合诊股面向单只A股泛化诊断，盈米偏基金/投顾分析；为避免把不同评分口径混进指数策略，本实现没有用它们替代指数官方数据。

### 6.2 每日运行

```bash
cd /workspace/index_rotation
pip3 install -r requirements.txt

python3 daily.py run                                  # 最新交易日，更新计划状态
python3 daily.py run --as-of 2026-11-20 --no-state     # 历史回算，不改状态
python3 daily.py run --offline                         # 只使用本地缓存
```

输出位置：

- `output/latest.md`：可直接阅读的最新信号卡
- `output/latest.json`：完整机器可读结果
- `output/daily/YYYY-MM-DD.md`：每日归档
- `output/history.csv`：每日信号与执行事件历史
- `data/live_state.json`：计划现金池、减仓档位、卖出池和幂等状态

macOS 每天 20:30 自动运行：

```bash
python3 install_schedule.py --time 20:30 --mode launchd
# 预览确认后：
python3 install_schedule.py --time 20:30 --mode launchd --install
```

Linux 服务器用 `--mode cron` 输出 crontab 行。节假日重复运行不会重复记账；建议服务器时区设为 `Asia/Shanghai`。
