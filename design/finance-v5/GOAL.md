# /goal 周期罗盘 · 金融资产模块 V5
在 ByteRax/cycle-compass 当前工作树执行本文件。目标是让用户能在同一观察池比较周期收益、解释一个数字、下钻到资产、原样返回，并能保存当天的报告或每日跟踪同一研究配置。直接修改代码、运行测试、修复并复验。交付可审查的本地改动。发布、推送和合并由维护者决定。

## 开工基线
记录分支、HEAD、已有改动及适用的 AGENTS.md。读取 apps/miniapp/src/pages-sub/{finance,divergence}、components/{finance,trend}、api/trend、stores/finance 和 services/api-go 对应 handler、查询、快照与测试。逐项标注已实现、部分实现、缺失及文件位置。历史审查基于 master，若现状已修复则以回归测试证明。保留行情、产业、策略和账本入口及旧深链。沿用 UniApp/Vue3/TypeScript/Pinia、weapp-tailwindcss、现有组件、Go/SQLite 和交易日历。先选一个有可展示历史数据的观察池；设计图中的金额、日期、覆盖数均为示意。未经授权的市场显示覆盖原因。线上不得使用设计样例或随机收益。

## 批次 A：修通既有功能
1. 统一路由编解码。研究条件包含 asset_id、scope_id、currency、range、chart、benchmark_id、snapshot_mode、snapshot_id。读取旧 id、pool_id 及旧 view 映射；优先显式参数，其次来源页面，最后用户偏好。校验枚举和编码异常。详情 openReport 发 asset_id，报告兼容 id。未知标的可返回重选。全景→详情→工作台→报告→微信分享恢复都走同一套编解码；保留资产身份与进入时的观察池。切换资产重验基准及快照适用性。
2. 区分用户选择的 latest/fixed 和查询实际返回的快照号。一次浏览链及其分页绑定实际快照，手动刷新后原子替换；每日跟踪收藏下次打开解析最新，固定收藏和本期报告锁定原快照。已过期历史显示原因，不能悄悄改成最新。
3. 全景查询由服务端在同池同快照先筛市场/类型/状态，再按稳定字段排序，以 asset_id 打破并列，最后分页。总览统计基于完整池，市场选项来自完整池，返回池总数、有效数、命中数和 cursor。切池、排序、筛选重置游标；过期游标提示刷新。分页不改变相对强度分母。统计失败显示“统计暂不可用”，零有效样本显示 0 个及占比 —。详情成分首次 30 条可继续加载，失败保留已有行并可重试。
4. 所有会随筛选、标的、币种、区间变化的异步请求使用取消或序号检查，旧响应不得更新数据、错误或 loading。available_charts 未加载、请求失败、空数组、有支持项分别渲染。历史不足的区间禁用并说明起始日期。删除无数据支撑的快捷入口或改由目录生成。
5. 导出按 chart 注册数据和渲染器。优先交付周期矩阵和趋势曲线；梯队、节气等已提供专用导出入口的图型要么完整画出成员和分组，要么明确按钮标为“导出资产摘要”。标题随实际内容生成。数据未加载、快照失效或取数失败不得生成成功海报。预览和保存共用同一渲染结果。

## 批次 B：周期矩阵与下钻
服务端一次批量取当前页各资产所需历史点，复用既有行情与复权口径，避免逐格 HTTP/SQL。接口返回快照、分组、列定义、收益类型、数据质量和分页信息。各单元格至少含 period_key、start_date、end_date、起止值、return_pct 或 null、reason。明确百分数单位，例如 2.31 表示 +2.31%。本周、本月、本季、今年取市场当地历法周期起点之前的有效收盘至截止日；去年取上一完整自然年。滚动 1M 独立显示。不同币种用各端点当时可用汇率；缺汇率、缺基期或收益类型不适用返回原因。债券收益率按 bp 单独表达，不混入价格回报排序。跨资产统一截止时点并保留实际交易日。趋势点只有存在对应期末状态时才绘制。增加跨年、休市、零收益、缺数据及汇率变动的数值测试。

页面尺寸按 375 CSS px 设计，并适配 320–430px。复用现有色彩 token、深浅主题与红涨绿跌偏好；数字等宽右对齐，方向同时用正负号表达。顶栏避开微信胶囊，底部操作避开安全区。图片不得直接嵌为业务界面。
- 全景：顶栏池名与搜索；第二行截止日和有效/总数；右侧确认、下行确认、形成中点按筛成员，再次点击清除。其余与未覆盖单独计数。行情表/周期矩阵保留同池、筛选和锚点。币种改为显式菜单，含原币说明。
- 矩阵：冻结名称列，单一横向滚动容器保持表头和行对齐，窄屏允许露出下一列。分组可折叠，表头选择升/降序并标明排序范围。点名称看详情，点数字开底部说明，含日期、价格、单位、收益类型和来源；“查看这段走势”使用该格实际起止日。单元格事件不冒泡至行。返回恢复折叠、排序、已加载页及行锚点。
- 详情：显示来自哪个池、强度排名分母、确认日期与持续交易日。图表横向查值、纵向交给页面，轻触选点，取消触摸恢复；真机验证滚动方向。入口仅展示适用视图。保留成分聚焦、梯队点成员、节气展开、分布点色块后二次下钻。
- 收藏与报告：明确“每日跟踪”和“保存本期”。导出当前筛选、币种、周期列、排序和范围，长表按组分页，跨页重复列头、日期与页码；过长组可续页。同一快照生成所有页。微信预览、保存相册、转发卡片分别处理权限拒绝、取消和失败，转发恢复固定条件。禁止私密收藏备注出现在分享参数中。

## 批次 C：验收与交付
在仓库现有测试框架中覆盖下列场景。执行 Go 相关测试、前端类型检查、Vitest 及 mp-weixin 构建，命令以当前 package.json/go.mod 为准。用微信开发者工具和可用真机完成录屏，记录设备、系统、构建、场景和结果。没有真机则标待验，不以 H5 代替。
1. 从两个资产详情分别导出，检查标题、资产、快照及实际图型；旧 id 链接能打开。
2. 非默认池选 USD→详情选 3M→工作台选基准→导出→另一会话开分享，字段逐项一致。
3. 唯一匹配资产排第 41；首次筛选即命中。详情第 31 个成分可达。加载下一页不改变池统计或已有排名。
4. 快速 1M→1Y→3M，人工延迟使响应倒序，最终标题、图和指标均为 3M。切池、币种和资产也测。
5. 空池、真实零、网络错误、无可用图、过期快照均可区分。详情失败时不出现七个假入口。
6. 在长表折叠一组，点另一个组的本月数字再看走势，返回后定位到原行。横滑表格、纵滑页面、图内取值在 iOS 和 Android 各验一次。
7. 分别保存跟踪和本期收藏，发布下一测试快照后重开，仅跟踪项更新。梯队导出的真实内容与按钮名一致；拒绝相册权限后可重试。
8. 320px 屏、微信大字号、深浅主题均可读，长资产名不挤出收益，零值不染成上涨。回归原四个一级入口。
交付变更文件及关键函数、接口及口径、测试命令/结果、截图或录屏、仍待验证项。按 A→B→C 实施，先走通一个真实观察池，再扩覆盖。设计图用于层级、布局和密度参考；文字、数据与行为以本规格和真实接口为准。
