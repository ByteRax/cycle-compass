# CycleCompass 周期罗盘 · 小程序改版设计 Spec

## 1. 项目定位与受众
- **产品名称**：周期罗盘（CycleCompass）
- **核心定位**：面向 A 股与全球宏观/指数定投研究者的微信小程序，打通「全球宏观与产业景气 → 周期罗盘定位 → 创业板50/红利低波100 量化双策略 → 800 交易日回测 → 模拟实盘账本」闭环。
- **使用场景与核心入口**：
  1. 回头客通过微信下拉「最近使用」在每周一开盘前/收盘后快速确认：当前在什么区间、本周定投该买谁还是进现金池、一键打卡记账。
  2. 投资同好在微信群收到 5:4 转发卡片（如「比值 0.1846 · 中间区 · 本周进现金池」或「恐慌指数 VIX 35.90 (+26.28%)」）点进来直接看信号与数据。
- **业务边界**：纯量化研究与模拟记账，不做真实交易与收益承诺；严格遵守中国市场 **红涨绿跌** 金融语义。

## 2. 现有界面核心痛点（基于源码与实机截图诊断）
1. 顶部 6 个水平滚动胶囊（全球/日韩/有色/AI/周期策略/模拟投资）右侧被裁切，缺少清晰的小程序主导航层级。
2. 首页落点是 8 张宏观白卡 + 24 张带 emoji（🧠💡🔬💾）的产业白卡，视觉同质、扫读效率低，没有体现「周期罗盘」的产品核心。
3. 周期策略页存在明显模板感与排版缺陷：紫蓝渐变卡带英文 `CURRENT PHASE` 装饰标、轮动标尺出现 `&lt; 0.16` 乱码且「低谷 0.14」与「现在 0.1846」重叠、「红利低波100 四维评分」与「门控通行」发生尴尬折行、四维评分条使用无关彩虹四色。
4. 缺少面向微信群传播的 5:4 转发卡片设计。

## 4. 输出格式与技术约束
- **形态**：微信小程序高保真交互展示板（3 个方向：`design-demos/dir-1.html`、`dir-2.html`、`dir-3.html`）。
- **统一尺寸**：展示板宽 `1440px`，每台手机严格使用 `WechatFrame`（`375×812` = 750rpx 基准，保留右上角微信胶囊与底部安全区），每版包含 **4 屏可交互页面 + 1 张 5:4 微信转发卡片（`WechatShareCard`）**。
- **小程序可落地约束**：无 emoji 图标、无装饰性背景图、纯 CSS + 轻量 SVG 图形（可 1:1 迁回 UniApp/Tailwind v4/WXML 工程）、正文 ≥ 12px（核心读数 ≥ 14px）、对比度 ≥ 4.5:1。
