## 入选完整版 · 方向一（`dir-1.html`）：精密航海罗盘 · 暗场仪器盘

- **逻辑与来源**：最佳设计师 #1 — Dieter Rams / Teenage Engineering 精密测量仪器设计思维（跨类目借鉴光学/航海仪表盘的刻度秩序）
- **借的是什么**：以「单屏一个核心精密仪表 + 等宽数字刻度表」组织信息，仪表盘占首屏视觉重心 45%，其余指标退居发丝线网格，不套多余卡片壳
- **不借的、自己长的**：不借硬件合成器的彩色方按键与点阵字；配色从夜航罗盘与金属蚀刻推导出墨曜石底 `#0D1114` + 暖白 `#F1EFEA` + 铜金刻度 `#D4A359`，搭配收敛的 A 股朱砂涨 `#E5534B` 与松石跌 `#2EBD85`
- **主入口与转发卡片**：微信下拉「最近使用」（周一盘前/盘后 10 秒看盘回头客）；5:4 转发卡片为深色精密罗盘切片 + 大字「0.1846 · 中间区 · 存现金池」
- **主屏形态 / 签名处**：首屏即为双环 SVG 周期罗盘（外环宏观四象限 + 内环 ERP 2.81% 与 88% 置信度弧线）+ 紧贴下方的三区间比值游标
- **数据的形状 / 颜色回答什么 / 嗓音**：圆环罗盘 + 精密游标 + 无边框等宽表；彩色只回答「涨跌」与「当前指向」；嗓音冷静克制如航海日志
- **导航与展示板**：底部 4-tab 深色原生 `tabBar`（策略 / 行情 / 产业 / 账本），`nav="custom"` 左对齐标题避让胶囊；展示板用 `layout="hero"` 主次构图
- **胆量花在哪**：首屏砍掉所有传统白卡片，让一枚 220px 双环精密罗盘直接成为界面的主角
- **form 来自内容的哪里**：「周期罗盘」本质就是一台校准宏观方位与风格偏航的精密仪器

## 入选完整版 · 方向二（`dir-2.html`）：财经报刊研报 · 暖纸排印版

- **逻辑与来源**：最佳设计师 #2 — 吕敬人书籍版式 × Financial Times Newsroom Chart System（数据新闻图表规范）
- **借的是什么**：结论句作头条（Assertion-Evidence）、1px 细线排列表格取代白卡片堆砌、水平等比例标尺直接嵌入数字标注、去图例与去彩虹色
- **不借的、自己长的**：不借 FT 标志性粉橘底或古籍竖排；配色从传统财经纸质研报与 CycleCompass 原品牌深蓝推导出暖纸底 `#F6F1E9` + 墨黑 `#1A1918` + 油墨藏青 `#1C355E` + 印章朱红 `#C63A2E` / 黛青绿 `#1B7A56`
- **主入口与转发卡片**：微信群/公众号文章点击进入的深度研报读者；5:4 转发卡片为报刊头条式卡片，白纸黑字刊头 + 结论句 + 迷你三区间标尺
- **主屏形态 / 签名处**：首屏像财经头版——顶部日期刊头 + 一句粗宋体结论断言，下方是严格按 0.10–0.50 数值比例绘制的**水平三区间轮动标尺**（彻底解决低谷/当前/峰值标注重叠）
- **数据的形状 / 颜色回答什么 / 嗓音**：等比例水平标尺 + 单色阶四维条 + 报刊细线行情表；颜色只回答「涨跌」与「行动指令」；嗓音专业笃定如机构每日收市纪要
- **导航与展示板**：底部 3-tab 清爽白底 `tabBar`（简报 / 盘面 / 账本），页内用极简文字下划线切换子板块；展示板用 `layout="closeup"`，中间 2x 局部特写放大三区间标尺与四维评分
- **胆量花在哪**：彻底放弃圆角阴影卡片，全屏用宋体头条、1px 发丝线与数据墨水比撑起高级感
- **form 来自内容的哪里**：量化双策略与 800 日回测的核心价值是一份冷静、可审计的每日收市投研简报

## 入选完整版 · 方向三（`dir-3.html`）：等高线周期地貌 · 任务路线流

- **逻辑与来源**：秒数轮盘 App 06 — **户外地形工具 Topo Outdoor**（跨类目借用等高线地貌与海拔剖面机制，结合 GO Club 实心刻度进度条）
- **借的是什么**：以「不规则等高线背景 + 历史海拔面积剖面 + 底部白色抽屉核心三读数」呈现空间水位感，让用户一眼看懂当前处于 10 年周期的山峰、山腰还是谷底
- **不借的、自己长的**：不借徒步路线里程/爬升/林地水体图标；配色从地质测绘图纸推导大地米沙底 `#EFECE2` + 赭棕等高线 `#B99768` + 深岩墨 `#1B2420` + 唯一高对比信号陶土朱 `#D94E28`（标定当前轨迹点与打卡主按钮）
- **主入口与转发卡片**：周一定投日单手快速执行任务；5:4 转发卡片为等高线水位切片 + 轨迹红点「当前水位 24.3% · 存现金池」
- **主屏形态 / 签名处**：首屏上半是 10 年比值等高线与海拔剖面图（带 0.16/0.28 两条海拔等高虚线与当前轨迹红点），下半白色抬升面板放三个窄体超大读数（`0.1846` / `6.57` / `¥1,000`）与一键打卡按钮
- **数据的形状 / 颜色回答什么 / 嗓音**：等高线海拔剖面 + 24 产业链色阶热力块 + 现金池水位刻度条；颜色回答「水位高低与涨跌」；嗓音干脆利落像向导指令（「当前在山腰，按兵不动，存 ¥1,000 进池」）
- **导航与展示板**：极简 2-tab 轻流程（`周期路线 / 我的账本`），把行情与产业收束在路线探索流中；展示板用 `layout="flow"`，4 屏斜向串联并画虚线箭头标明「点击打卡 / 展开回测」路径
- **胆量花在哪**：把抽象的指数比值变成肉眼可感的「十年周期海拔剖面」，且大胆精简为 2-tab 即用即走流
- **form 来自内容的哪里**：经济与市场周期本来就有峰顶、低谷与分水岭，地形海拔是最直觉的周期心智模型
